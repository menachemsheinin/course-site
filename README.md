# אתר הקורס: כלים דיגיטליים א׳

אתר סטטי בעברית. כל התוכן נמצא בקבצי JSON בתיקיית `data/`. כל שינוי שנשמר ב-GitHub מתפרסם אוטומטית באתר תוך דקה-שתיים.

## הקמה חד-פעמית (כ-5 דקות)

1. ב-GitHub: **New repository**, שם למשל `digital-tools-course`, ציבורי.
2. העלו אליו את כל תוכן התיקייה הזו (כולל התיקייה המוסתרת `.github`).
3. ב-GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. בלשונית **Actions** תראו את הפריסה רצה. בסיומה הכתובת תופיע ב-Settings → Pages:
   `https://<שם-המשתמש>.github.io/digital-tools-course/`
5. שלחו לסטודנטים את הכתובת.

## עדכון תכנים

| מה לעדכן | איזה קובץ |
|---|---|
| הודעות, ציון, כותרת | `data/course.json` |
| מפגשים: הרצאה, תרגול, חומרים | `data/sessions.json` |
| תרגילים: פתיחה, הגשה | `data/exercises.json` |
| רשימת נושאים לפרזנטציות | `data/presentations.json` |
| קישורים לכלים | `data/tools.json` |

העריכה אפשרית ישירות באתר GitHub (סמל העיפרון על הקובץ, אחר כך **Commit changes**), או מהמחשב עם `git push`.

### דוגמאות

**לפרסם תרגיל:** ב-`exercises.json` שנו `"status": "soon"` ל-`"open"` והוסיפו `goal`, `tasks`, `deliverable`. אפשר גם `files` (קישורים לקבצים), `submitUrl` ו-`due` (תאריך בפורמט `2026-11-10`).

**להוסיף חומר למפגש:** ב-`sessions.json` הוסיפו למפגש:
```json
"materials": [{ "title": "מצגת מפגש 3", "url": "https://..." }]
```

**לסמן נושא שנבחר:** ב-`presentations.json` הוסיפו לפריט `"takenBy": "שלשה 4"`. הוא יסומן באתר כ״נבחר״.

**לפרסם הודעה:** הוסיפו ל-`announcements` ב-`course.json` פריט עם `date` ו-`text`.

**קבצים (PDF, DWG, תמונות):** העלו לתיקייה חדשה `files/` ושימו קישור יחסי, למשל `files/base-plan.dwg`.

## בדיקה מקומית

```
python3 -m http.server 8000
```
ואז לפתוח `http://localhost:8000`. (פתיחה ישירה של `index.html` לא תעבוד, כי הדפדפן חוסם קריאת קבצי JSON.)

## הערות

- אם קובץ JSON נשבר (פסיק חסר, גרשיים), הפריסה נעצרת עם הודעת שגיאה בלשונית Actions והאתר הקודם נשאר פעיל.
- רשימת הפרזנטציות מוצגת באתר אבל רישום הסטודנטים מתבצע מחוץ לו. הדביקו ב-`signupUrl` קישור לטופס או לגיליון משותף, והכפתור יופיע.
- אין באתר התחברות או מידע אישי. אל תעלו אליו ציונים או פרטי סטודנטים, כי הוא ציבורי.
