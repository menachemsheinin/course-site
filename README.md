# אתר הקורס: כלים דיגיטליים א׳

אתר סטטי בעברית. כל התוכן נמצא בקבצי JSON בתיקיית `data/`. כל שינוי שנשמר ב-GitHub מתפרסם אוטומטית באתר תוך דקה-שתיים.

## הקמה חד-פעמית (כ-5 דקות)

1. ב-GitHub: **New repository**, שם למשל `digital-tools-course`, ציבורי.
2. העלו אליו את כל תוכן התיקייה הזו (כולל התיקייה המוסתרת `.github`).
3. ב-GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. בלשונית **Actions** תראו את הפריסה רצה. בסיומה הכתובת תופיע ב-Settings → Pages:
   `https://<שם-המשתמש>.github.io/digital-tools-course/`
5. שלחו לסטודנטים את הכתובת.

## עדכון תכנים

| מה לעדכן | איזה קובץ |
|---|---|
| הודעות, ציון, כותרת | `data/course.json` |
| מפגשים: הרצאה, תרגול, חומרים | `data/sessions.json` |
| רשימת נושאים לפרזנטציות | `data/presentations.json` |
| קישורים לכלים | `data/tools.json` |

העריכה אפשרית ישירות באתר GitHub (סמל העיפרון על הקובץ, אחר כך **Commit changes**), או מהמחשב עם `git push`.

### דוגמאות

**להוסיף חומר למפגש:** ב-`sessions.json` הוסיפו למפגש:
```json
"materials": [{ "title": "מצגת מפגש 3", "url": "https://..." }]
```

**לסמן נושא שנבחר:** ב-`presentations.json` הוסיפו לפריט `"takenBy": "שלשה 4"`. הוא יסומן באתר כ״נבחר״.

**לפרסם הודעה:** הוסיפו ל-`announcements` ב-`course.json` פריט עם `date` ו-`text`.

**קבצים (PDF, DWG, תמונות):** העלו לתיקייה חדשה `files/` ושימו קישור יחסי, למשל `files/base-plan.dwg`.

## בדיקה מקומית

```
python3 -m http.server 8000
```
ואז לפתוח `http://localhost:8000`. (פתיחה ישירה של `index.html` לא תעבוד, כי הדפדפן חוסם קריאת קבצי JSON.)

## הערות

- אם קובץ JSON נשבר (פסיק חסר, גרשיים), הפריסה נעצרת עם הודעת שגיאה בלשונית Actions והאתר הקודם נשאר פעיל.
- רשימת הפרזנטציות מוצגת באתר אבל רישום הסטודנטים מתבצע מחוץ לו. הדביקו ב-`signupUrl` קישור לטופס או לגיליון משותף, והכפתור יופיע.
- אין באתר התחברות או מידע אישי. אל תעלו אליו ציונים או פרטי סטודנטים, כי הוא ציבורי.

## שיבוץ חי לנושאי הפרזנטציות

בעמוד "רקע ← פרזנטציות" כל שלשה בוחרת נושא ותאריך הצגה (ושמות חברי השלשה), והנושא נתפס לכולם מיד. בכל תאריך יש מקסימום מקומות (3), ותאריך מלא נסגר לבחירה. מעל הרשימה מופיע לוח שמראה מי מציג בכל תאריך. העמוד מתעדכן לבד כל כמה שניות. השיבוצים נשמרים ב-Netlify Blobs, והלוגיקה בקובץ `netlify/functions/claims.mjs`.

**הגדרה חד-פעמית ב-Netlify:** Site configuration ← Environment variables ← Add a variable:

| משתנה | משמעות |
|---|---|
| `CLASS_CODE` | אופציונלי: קוד כיתה. אם לא מגדירים, כל אחד יכול להירשם בלי קוד. |
| `ADMIN_KEY` | סיסמה ארוכה לדף הניהול `admin.html`. בלעדיה אי אפשר לשחרר או לשבץ ידנית. |

אחרי שמוסיפים משתנים צריך לפרסם מחדש (Deploys ← Trigger deploy).

**ניהול:** `https://<כתובת-האתר>/admin.html`, מזינים את `ADMIN_KEY`. אפשר לשחרר שיבוץ, לשבץ ידנית ולשנות שמות.

**תאריכים:** התאריכים והמקסימום נלקחים אוטומטית מ-`data/sessions.json`: כל מפגש עם `"presentations": 3` בחלק `bg` הוא תאריך הצגה. לשינוי מספר המקומות משנים את המספר שם. תאריך שעבר נחסם לסטודנטים, והמרצה יכול לשבץ בו ידנית.

**הרשימה:** כל נושא צריך `id` יציב ב-`data/presentations.json` (לא לשנות אחרי שהתחילו שיבוצים). שינוי שם או תיאור לא פוגע בשיבוץ.

**פרטיות:** האתר ציבורי, ולכן שמות הסטודנטים שנרשמו גלויים לכל מי שנכנס לעמוד.

## תרגילים וגלריית תוצרים (קורס יישום ← תרגילים)

לכל אחד מחמשת התרגילים יש לשונית משלו (`#/app/exercises/1` עד `/5`), עם אייקון "דרישות התרגיל" בראש העמוד, העלאה, וגלריה. הדרישות נטענות מ-`data/exercises.json`: לכל תרגיל אפשר `title`, `goal`, `deliverable`, `steps` (רשימת שלבים עם `title` ו-`text`), `total`, `requirements` (רשימה פשוטה) ו-`links`. תרגיל בלי תוכן מציג "דרישות התרגיל יימסרו בהמשך".

הסטודנט כותב את שמו ומעלה תמונה, והיא מוצגת מיד בגלריה של אותו תרגיל. הדפדפן מכווץ אותה אוטומטית ל-JPEG איכותי (עד 2400 פיקסלים בצלע הארוכה), ושומר גם תמונה ממוזערת. לחיצה על תמונה פותחת הגדלה למסך מלא (חצים מחליפים תמונה, Esc סוגר, וקישור לפתיחה בגודל מקורי).

- **PDF:** אפשר להעלות גם PDF (עד 4MB). הדפדפן מצייר את העמוד הראשון כתמונה לגלריה (בעזרת pdf.js בתיקייה `assets/vendor`, רישיון Apache-2.0), והקובץ המלא נשמר וזמין בקישור "פתיחת ה-PDF המלא" בהגדלה.
- **דוגמה בדרישות:** תמונת הדוגמה של תרגיל 1 נמצאת ב-`assets/ex1-example.jpg` ומוגדרת בשדה `example` ב-`data/exercises.json`.
- **מגבלות (לכל תרגיל):** עד 3 תמונות לכל דפדפן, עד 150 תמונות בסך הכול, תמונה אחת עד כ-4MB אחרי כיווץ.
- **מחיקה:** סטודנט מוחק רק את התמונות שהעלה (מאותו דפדפן). המרצה מוחק כל תמונה ב-`admin.html` (פרק "גלריית התרגילים", בחירת תרגיל).
- **קוד:** `netlify/functions/gallery.mjs`, `netlify/lib/gallery-core.mjs`, `assets/gallery.js`, וביטוי העמוד ב-`assets/app.js` (`gallery()`). הקבצים נשמרים ב-Netlify Blobs.
- אם מגדירים את `CLASS_CODE` ב-Netlify, ההעלאה תדרוש אותו (הצפייה נשארת חופשית).
- **פרטיות:** האתר ציבורי, ולכן התמונות והשמות גלויים לכל מי שנכנס לגלריה.
